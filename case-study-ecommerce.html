Overview

What this project is

This project is an interactive Power BI dashboard built for a US-based ecommerce company to track Year-To-Date sales performance. Data is pulled directly from MS SQL Server and flat files, modeled across three related tables, and enriched with DAX time-intelligence measures (YTD, PYTD, YoY) to surface category, regional, product, and shipping-level performance in a single executive view.

Business Problem

Why it matters

A US-based ecommerce company needed a single view of Year-To-Date sales performance — not just totals, but growth versus last year, which categories and products were winning or losing ground, which states and regions were driving revenue, and which shipping method customers actually used most. None of that is visible from raw transactional tables in SQL Server without a modeled, DAX-driven dashboard on top.

Requirements (BRD)

What the dashboard needed to answer

  • Create a KPI Banner showing YTD Sales, YTD Profit, YTD Quantity Sold, and YTD Profit Margin
  • Find Year-on-Year growth for each KPI, with a YTD sparkline showing the monthly trend
  • Find YTD Sales, PYTD Sales, and YoY Sales growth by customer category, with a trend icon per category
  • Find YTD Sales performance by each state
  • Identify Top 5 and Bottom 5 products by sales
  • Break down YTD Sales by region to find the best and worst performing regions
  • Break down YTD Sales by shipping type to get the best shipping type percentage
Dataset

What the analysis is built on

Ecommerce transaction data — orders, products, categories, customer segments, regions, states, and shipping types — imported into MS SQL Server and connected live to Power BI, alongside supporting flat files.

Methodology

How it was approached

Process

  • Problem statement & requirements gathering
  • Import data into MS SQL Server
  • Connect Power BI to the SQL database
  • Data cleaning in Power Query
  • Data modeling across three tables
  • Custom Date Table + time intelligence DAX
  • Visualization, dashboard build, and insights

Power BI skills applied

  • Time intelligence — TOTALYTD, SAMEPERIODLASTYEAR
  • Dynamic, complex KPIs with conditional formatting
  • DAX — CALCULATE, SUMX, FILTER, VALUES, SELECTEDVALUE, VAR, DIVIDE
  • Dynamic trend icons per category
  • Map, donut, and table visualizations
  • Segment-level filtering (Consumer / Corporate / Home Office)
Dashboard

The final result

A KPI banner with YoY badges and sparklines, a segment toggle, a category performance table, top/bottom product charts, and region/state/shipping breakdowns — interact with the live report below.

Key Insights

What came out of it

  • YTD Sales stood at $11.53M, down -0.83% YoY, while YTD Profit grew to $1.34M, up +4.50% YoY — profit growing even as revenue dipped slightly
  • YTD Profit Margin improved to 11.28%, up +5.37% YoY
  • YTD Quantity sold fell -7.29% YoY to 107.2K units — fewer units sold, but at a higher margin per unit
  • Office Supplies was the largest category by YTD Sales ($6.92M), followed by Furniture ($2.52M) and Technology ($2.10M); Office Supplies and Technology both declined YoY while Furniture grew
  • Staple envelope, Staples, and Easy-staple paper were the top 3 products by YTD Sales
  • West was the strongest region at 32.22% of YTD Sales, while South lagged at 16.17%
  • Standard Class dominated shipping at 60.51% of YTD Sales, followed by Second Class (19.22%), First Class (15.1%), and Same Day (5.17%)
