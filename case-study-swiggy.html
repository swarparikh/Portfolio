Overview

What this project is

This project analyzes Swiggy's food delivery sales performance across India — twice, two different ways. First as an interactive Excel dashboard (Power Query, Power Pivot, DAX, PivotCharts) built for executive reporting. Then again as a Python notebook (Pandas, NumPy, Matplotlib, Seaborn, Plotly) that independently rebuilds the same KPIs and charts from the same BRD, using code instead of a workbook.

Business Problem

Why it matters

Raw Swiggy order-level data on its own doesn't answer the questions a business actually asks: which cities and states are driving revenue, whether veg or non-veg orders dominate sales, how performance shifts week to week and quarter to quarter, and where customer satisfaction stands. A Business Requirements Document (BRD) was used to define exactly which KPIs and charts stakeholders needed before any dashboard work began.

Requirements (BRD)

KPIs and charts defined upfront

KPI's

  • Total Sales (₹) — overall revenue from food orders
  • Average Rating — customer satisfaction across restaurants
  • Average Order Value (₹) — revenue per order
  • Ratings Count — total customer reviews
  • Total Orders — number of food orders received

Chart's

  • Monthly Sales Trend
  • Daily Sales Trend
  • Total Sales by Food Type (Veg vs Non-Veg)
  • Total Sales by State (map visualization)
  • Quarterly Performance Summary
  • Top 5 Cities by Sales
  • Weekly Trend Analysis

Dataset

What the analysis is built on

Swiggy order-level sales data covering restaurant name, food category (Desi Ghee, Chinese, Pasta, Roll, Sides, and more), state, city, order date, rating, and order value — cleaned and modeled entirely inside Excel using Power Query and Power Pivot.

Python Analysis

Rebuilding it in code

The same BRD was rebuilt independently in a Python notebook — loading the raw dataset with Pandas, computing all five KPIs directly from the raw fields, engineering a Veg/Non-Veg classifier from dish-name keywords, and charting every BRD requirement with Matplotlib, Seaborn, and Plotly Express.

Process

  • Loaded and inspected data with Pandas (dtypes, describe, shape)
  • Calculated KPIs directly from raw fields
  • Engineered a Veg/Non-Veg feature via keyword matching on dish names
  • Grouped and aggregated by month, day, quarter, week, state, and city

Libraries used

  • Pandas & NumPy — cleaning, feature engineering, aggregation
  • Matplotlib — monthly and daily trend charts
  • Plotly Express — food-type split, state, city, and weekly charts

Key Insights

What came out of it

  • Total Sales reached ₹53.01M across 197,430 total orders, with an average rating of ~4.3, confirmed identically by both the Excel and Python analyses
  • Average order value stood at ₹268.51, backed by 5.59M customer ratings
  • Bengaluru led all cities in both analyses, followed by Lucknow, Hyderabad, Mumbai, and New Delhi
  • Q2 recorded the highest quarterly sales, slightly ahead of Q1
  • Saturday was the strongest day of the week for revenue in the Python daily-trend breakdown
  • Veg orders made up 63% of total sales vs 37% for Non-Veg — confirmed independently by both the Excel dashboard's category field and the Python notebook's keyword-based classifier
